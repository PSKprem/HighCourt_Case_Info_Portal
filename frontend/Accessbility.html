Accessibility Statement - CS Web

We are committed to ensuring that the CS Web platform is accessible to all users irrespective of the device, technology, or ability. It is designed with an aim to offer maximum accessibility and usability for visitors. This web platform can be accessed via a wide range of devices including desktop computers, laptops, and web-enabled mobile devices.

Our website aims to ensure accessibility for individuals with disabilities. For instance, users with visual impairments can access this platform using assistive technologies such as screen readers and magnifiers.

We follow standard accessibility and usability practices adhering to the principles of universal design. CS Web uses modern technologies like HTML, CSS, JavaScript, Flask, FastAPI, and Beautiful Soup. Charts and analytics are presented using Chart.js. The platform is developed following the Guidelines for Indian Government Websites and aligns with Level A of the Web Content Accessibility Guidelines (WCAG) 2.0 set by the World Wide Web Consortium (W3C).

Some parts of the platform may contain links to external websites which are maintained by their respective authorities. We do not guarantee the accessibility of those external resources.

Please note that Portable Document Format (PDF) files and some case data might not yet be fully accessible. We are continuously working to improve this.

If you encounter any accessibility issues or have suggestions to enhance the experience, please write to us at support-csweb@csweb.gov.in with a description of the problem and your contact details.
