Project Information

This website is a High Court Case Portal developed for easier access to case details. Users can search for cases, download PDFs, and view judgments.

Purpose: Help government officials, legal professionals, and citizens get case data easily.

  • Built with: HTML, CSS, JavaScript, Flask, FastAPI
  • Used tools: BeautifulSoup for web scraping, Chart.js for dynamic visualizations
  • Offers PDF + Text format for accessibility
  • Search by voice for differently-abled users
  • Dynamic Graphs State-wise

Want to learn more? Chart.js Docs, BeautifulSoup Docs
