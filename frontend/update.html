Backend Improvements
May 5, 2025
Initially, the system only supported case data for the Sikkim High Court. Later, Tripura High Court data was integrated after facing and overcoming multiple scraping issues. This led to a transition from basic scraping to using APIs, which currently work successfully for both Sikkim and Tripura. We are actively working on expanding this support to more states.

Search capabilities have also improved. Originally limited to exact name or case number lookups, Tripura now supports a free text search area and date range filters, enhancing usability. However, due to PDF data extraction challenges, Sikkim supports only name-based search for now. Search results display relevant information in a well-structured table with downloadable PDF links.
Frontend Enhancements
May 5, 2025
The frontend has evolved from a simple homepage and static search bar into a more refined, interactive, and medium-level responsive interface. Features like clickable cards, stylish dropdowns, and intuitive design elements now provide users a visually appealing and user-friendly experience. Continuous improvements are being made to further polish and optimize both design and functionality.
