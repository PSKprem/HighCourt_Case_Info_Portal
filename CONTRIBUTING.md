# Contributing

Thanks for your interest in improving the High Court Case Info Portal!

## Getting started

1. Fork the repository and clone your fork.
2. Follow [docs/SETUP.md](docs/SETUP.md) to run the project locally.
3. Create a branch for your change:
   ```bash
   git checkout -b feature/my-change
   ```

## Making changes

- Keep commits small and focused - one logical change per commit.
- Write clear commit messages (e.g. `Add year filter to insights endpoint`).
- Match the existing code style.
- If you change the backend API, update [docs/API.md](docs/API.md).
- If you add or change frontend pages, update [docs/FRONTEND.md](docs/FRONTEND.md).

## Submitting

1. Push your branch to your fork.
2. Open a Pull Request against `main` with a short description of what and why.

## Reporting issues

Open an issue describing:
- what you expected,
- what actually happened, and
- steps to reproduce.

## Code of conduct

Be respectful and constructive. We want this to be a welcoming project for
contributors of all experience levels.
